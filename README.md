# جاهزية المنشآت الصحية

نسخة ويب تجريبية معتمدة للتجربة على GitHub Pages.

- Dashboard للمنشآت شفا 1 إلى شفا 21.
- البلاغات النشطة في أعلى لوحة المتابعة.
- نموذج البلاغ: نوع البلاغ + أخرى، مصدر الكهرباء، نطاق التأثير كلي/جزئي، القسم المتأثر، تأثير البلاغ على الخدمات، مصدر البلاغ، اسم المبلّغ، الوصف والملاحظات.
- إغلاق البلاغ ينقله إلى السجل.
